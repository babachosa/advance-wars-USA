Lưu glyphs.json, đặt vào thư mục font_pixel thay file cũ, rồi chạy tại thư mục game:
python font_pixel/build_font.py build
python font_pixel/build_font.py check
Thao tác trong bảng chỉ đổi bản đang mở. Nút Lưu xuất file về máy. Script kiểm tra khoảng hở và pixel trước khi tạo ROM Pixel Font. Râu của ơ/ư và gạch của đ là nét liền có chủ ý.
